# yt-dlp GUI (v1.1.0)

Python (PySide6) と `yt-dlp` を使用したポータブル動画・音声ダウンロード GUI アプリケーション。

## 🌟 主な機能

1. **単体動画・音声ダウンロード**:
   - URL 解析による自動解像度・FPS・音質一覧の取得と選択。
   - **範囲指定トリミング ＆ 480x270 大画面プレビュー機能**: 別ウィンドウで動画・音声を完全同期再生しながら直感的にトリミング範囲（開始・終了時刻）を設定可能。
2. **一括ダウンロード (複数ダウンロード)**:
   - 「チャンネル / プレイリスト URL」専用入力枠と「個別URLリスト」枠を完全分離。
   - **YouTube チャンネル / プレイリスト対応**: 通常動画 (Videos) や Shorts などの動画1本1本を事前解析・自動展開し、総本数分の個別キュー項目として視覚化して順次ダウンロード。
   - **自由な `.txt` ファイル指定**: ファイル選択ダイアログにより、任意の名前のテキストファイルを開いて読み込み・名前を指定して保存が可能。
3. **yt-dlp バージョン管理**:
   - 起動時の自動最新バージョンチェック・更新機能。
   - 過去バージョンのバックアップ保存およびワンクリック・ダウングレード（復元）機能。
4. **縦スクロール対応 (QScrollArea)**:
   - ウィンドウ縮小時や小解像度画面でもUIが崩れない自動縦スクロール機能。

## 🚀 実行方法

```bash
pip install -r requirements.txt
python main.py
```
